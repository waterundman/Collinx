## 发现的两个真实缺陷（已修 + 已加护栏）

### 1. 设置浮层的 Esc 会「失效」

- **现象**：在设置里点掉一个按钮（例如移除 MIDI 效果）后，焦点回到 `body`，此时按 Esc 毫无反应 —— 用户被卡在设置里，只能去找关闭按钮。
- **根因**：关闭逻辑挂在设置容器的 `onKeyDown` 上，事件从 `body` 发起时根本不经过容器。
- **修复**：改为 `document` 级 `keydown` 监听（模态框本该如此，与焦点位置无关），并给根节点补 `data-testid="settings-page"` 便于断言。
- **护栏**：`Settings/__tests__/SettingsModalWiring.test.tsx` 新增 S1-T02c（先 blur 再在 body 上派发 Esc）。

### 2. i18n 重复键把对象覆盖成字符串

- **现象**：设置侧栏第 8 项显示原始 key `settings.plugins.title`。
- **根因**：`zh-CN.json` / `en.json` 里 `settings.plugins` 出现了两次 —— 本轮新增的对象块，和一行遗留的 `"plugins": "插件管理"`。`JSON.parse` 保留**最后一个**，于是对象被字符串静默覆盖。语言对称性测试抓不到（两边都是同样字符串）。
- **修复**：删除遗留字符串键（TS 侧零引用）。
- **护栏**：`i18n/__tests__/settings-keys.test.ts` —— 新增 key 必须 `t(k) !== k`，且 `settings.plugins` 必须是对象。**负控实测**：把字符串键加回去，该文件 2 条立即变红。

## 脚本侧踩的四个坑（写下来避免重踩）

1. `[data-testid^="arrangement-start-"]` 会先命中容器 `arrangement-start-grid`，点击落在无处理器的 div 上 —— 必须 `:not(...)` 排除。
2. 图谱节点画在 canvas 上，没有 DOM 锚点；且**力导向布局会随工程内容重排**，固定坐标（既有 e2e 用的 `(200,200)`）在改动过数据后必然落空 → 改为读像素、按 20px 网格找高亮团心依次点击。
3. 设置页本身是 `role="dialog"`，通用的"每步前清场"逻辑会把它当成残留弹窗关掉 → 加 `keepDialog` 选项。
4. 打开过弹窗却不清场，会让后续每一步都 30s 超时级联失败 —— 表现为"看起来全挂了"，实际只是一个未关闭的遮罩。
