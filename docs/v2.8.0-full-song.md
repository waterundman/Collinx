## 过程中修掉的真问题

### 钢琴卷帘音符"看不见"（`2fb0562`）

上一轮误判为配色问题。这次加临时探针读出真实坐标：

```
NOTE_HEIGHT = 18，canvas 高 228
第一个音符 pitch=40 → ny = (108-40) × 18 = 1224
```

**音符被画在画布下方 1200px 处**：音域总高 1584px，画布只 228px（≈12 个半音），
`scrollY` 默认 0 → 视口停在 C8，而音乐在 C2~C5。

修复：视口内无音符时自动对准音符平均音高（用户手动滚动不会被打断）。
像素验证：`purpleSamples 0 → 849`。

### 混音台电平 100%（削波）

466 个音符叠加后总电平打满 → 电平表准确反映了这个问题（说明表是真实的）。
**这不是 bug，是作品需要混音**：5 条轨全部以默认增益叠加必然过载。
