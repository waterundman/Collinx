# v2.8.0 能力对比：当前实现 vs 最初判断

> 2026-10-22｜对照 `docs/v2.8.0-song-feasibility.md`（最初的能力判断）
> 验收方式：全量点击测试 32/32 通过（`.audit/scripts/click-audit.mjs`）

## 一、九项能力对比

| # | 能力 | 最初判断 | 当前实现 | 结论 |
|---|---|---|---|---|
| 1 | 曲式结构 | ✅ Section + 编排器 | 同左 + 变体生成（实测 generate → 4 个 variant） | **≥** |
| 2 | 写旋律 | ✅ Piano Roll + MIDI 录制 + 量化 | 同左（piano-roll-draw/select/quantize/zoom 全部可点） | **≥** |
| 3 | 和声 | ✅ AI 建议 + 生成动机 | 同左 + `suggestHarmony` 调式（major/minor 三路归一化） | **>** |
| 4 | 配器（多轨） | ⚠️ **固定 3 轨** | **可加轨道**（4→4 模态框流程可用）+ 配器器出 5 轨 | **>** |
| 5 | 音色 | ❌ **无法选音色** | **5 种音色**按轨道自动分配（`instruments.ts`）；仍无手动选择 UI | **>** |
| 6 | 混音 | ⚠️ 推子 + FX 建议，**无电平表** | **有实时电平表**（实测 70%→100% 随推子变化）+ 推子 + FX 建议 | **>** |
| 7 | 母带 | ⚠️ 有 Master 轨，无处理 | Master 总线 + 电平表；**处理链仍缺** | **≥** |
| 8 | **试听** | ❌ **无声**（根本缺口） | **有声**：`AudioPreview` 内部合成器，实测振荡器 90+ / 4 种波形 | **彻底解决** |
| 9 | 导出 | ⚠️ MIDI / MusicXML / PDF，**无音频** | 上述全部 + **WAV**（21.4MB / 121.5 秒 / 2ch 44.1kHz 16bit） + `.agentmusic` 工程文件 | **>** |

## 二、原始场景结论对比

| 场景 | 最初 | 当前 |
|---|---|---|
| 画出一首歌（音符+结构+和声+乐谱+MIDI） | ✅ 完整可用 | ✅ 同上，另可存 `.agentmusic` |
| 听到一首歌 | ❌ **完全无声** | ✅ **有声**（无 MIDI 设备时走内部合成器） |
| 拿到能听的成品 | ❌ 只有 MIDI/PDF | ✅ **WAV 2 分 01 秒** |
| 做出有层次的编曲 | ❌ 固定 3 轨、无音色 | ⚠️ **部分**：可加轨、有 5 音色，但**无手动选音色 UI** |

## 三、仍不达标的项（如实列出）

| 项 | 现状 | 差距 |
|---|---|---|
| 音色手动选择 | 按 trackId 名称自动分配 5 种 | 无 UI 让用户挑 |
| 母带处理链 | 只有 Master 总线 + 电平 | 无 EQ/压缩/限幅 |
| 混音削波 | 466 音符 × 5 轨默认增益叠加会到 100% | 电平表准确反映了问题，但无自动增益/限幅 |
| 和弦轨 | `suggestHarmony` 产出和弦事件 | 无独立的 Chord Track 编辑界面 |

## 四、本次全量点击验收

9 个页签 + 传输控制 + 设置 + 顶栏保存，**32/32 通过**。

过程中修掉的脚本问题（都不是产品缺陷）：
- Taste 报告是自绘 overlay，Escape 关不掉 → 用 CSS 隐藏（**不能 `el.remove()`**，会破坏 React 的 `insertBefore`，整页渲染崩）
- `mixer-add-track` 只开模态框，要填「名称+来源」再确认才真加轨
- `transport-count-in` 只在激活时渲染，不能断言"存在"
- 设置是顶栏 `open-settings` 打开的 modal，不是页签
