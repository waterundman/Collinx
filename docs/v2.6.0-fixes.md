## 一、色彩系统收敛（taste-critic #8/#9/#10/#11/#12 → 一次重构消五条）

| 问题 | 处理 |
|---|---|
| 158 个 token、死 token 27 个 | 删除 27 个零引用 token；20 个"仅 JS 引用"（canvas 类）保留 |
| 同色多名（30 组） | 归一为语义源：`--canvas*` → `var(--bg-primary)`、`--score-ink`/`--button-text` → `var(--text-primary)`、`--accent-sunset-ink` → `var(--accent-sunset)` 等 |
| 焦点环是第三套强调色（橙 `#ff7a17`） | `--border-focus` → `var(--accent-primary)`；`:root` 补 `--accent-primary: var(--accent-cyan)` 成为唯一品牌色入口 |
| 浅色主题零面层级（surface/elevated/primary 三者皆白） | 改为「浅灰页底 + 白色面板」：`--bg-primary: #f5f6f8`，层级结构与暗色一一对应 |
| 浅色链接 1.82:1 | `a {}` 已改用 `--accent-primary`；死 token `--accent-breeze` 删除 |
| **被引用但从未定义的 token（7 个）** | `--border` / `--border-subtle` / `--surface-secondary` / `--danger-primary` / `--success-primary` / `--bg-tertiary` / `--text-tertiary` 此前被 CSS 引用却无定义，浏览器丢弃 → 相关声明静默失效（如顶栏按钮 hover 从未变色）。补齐为语义别名 |

新增审计脚本 `.audit/token-audit.mjs`：统计引用数与同值多名。**口径教训**：`getCSSVar("--x")` 这类 JS 字符串引用必须与 `var(--x)` 一起统计，否则会误删 canvas 类 token。
